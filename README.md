# 📊 Sales Analysis & Forecasting

## Overview
This project focuses on analyzing historical sales data to uncover meaningful business insights and predict future sales trends using machine learning models. It combines **data analytics, visualization, and predictive modeling** to demonstrate an end-to-end data science workflow that supports data-driven decision-making.

The project was initiated during my participation in the **Women ReBOOT Programme**, where it was developed and presented as a **pitch presentation**. Further enhancements and experimentation are currently in progress.

---

## 🎯 Objectives
- Understand historical sales patterns and trends
- Clean and prepare raw sales data for analysis
- Perform exploratory data analysis (EDA) to identify key drivers of sales
- Build and evaluate machine learning models for sales forecasting
- Present insights in a clear and business-friendly manner

---

## 🛠️ Tools & Technologies
- **Programming & Analysis:** Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn)
- **Machine Learning Models:**  
  - Linear Regression  
  - Random Forest Regression
- **Data Visualization:** Tableau, Matplotlib, Seaborn
- **Data Formats:** Excel (raw and cleaned datasets)
- **Version Control & Documentation:** GitHub
